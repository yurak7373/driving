# 개발 기록

## 2026-11-24 · Phase 00

- 초기 저장소에 있던 README 제목을 유지하면서 Codespaces 실행 절차를 추가했습니다.
- Three.js, TypeScript, Vite, ESLint, Prettier, Vitest 및 Playwright를 구성했습니다.
- PC 키보드와 모바일 화면 버튼이 같은 방식으로 제어하는 3D 테스트 장면을 만들었습니다.
- GitHub Actions와 한국어 작업 원칙, 구조 및 검수 문서를 추가했습니다.
- 잠금 파일을 커밋해 Codespaces와 CI에서 `npm ci`로 같은 의존성을 설치하도록 구성했습니다.
- 최초 의존성 감사에서 발견한 문제를 해결하기 위해 개발 도구를 업데이트했습니다. Node.js 22.13 이상이 필요합니다.
- 환경 실행 및 검수 결과는 [QA 보고서](QA_REPORT.md)에서 확인합니다.

## 2026-11-24 · Phase 00 QA 보완

- 두 카메라 시점에서 이동 영역과 표식 크기를 화면에 맞추고, 화면 크기 변경 후에도 좌표를 유지합니다.
- Codespaces 초기화와 CI에서 Chromium 헤드리스 셸 및 Linux 시스템 라이브러리 설치를 명시했습니다.
- 키 매핑, 실제 카메라 전환, 화면 경계 및 배포 빌드 검사를 보강했습니다. 브라우저 검사는 개발 서버 5174와 배포 미리보기 4174를 사용합니다.

## 2026-11-24 · Phase 01-A 버스 외부

- 가상의 해안시 대형버스 외형, 6개 바퀴, 문과 창의 개구부, LED와 여러 도색을 추가했습니다.
- 표식 시험 장면과 버스 관찰 장면을 오갈 수 있습니다. 관찰 화면에서 시점과 확대, 도색, 검수용 조향·회전을 조작합니다.
- 장면과 차량 자원의 소유권 및 정리 경로를 정의하고 반복 전환을 검수합니다.
- Phase 01-B에서 기존 앵커에 운전석·실내를 연결하고, Phase 01-C에서 앞문과 중문의 개폐를 연결합니다.

## Phase 02~03 예정

지속 조향·가속·제동, 복수 키, 모바일 멀티터치 및 자이로 입력을 공통 제어로 처리합니다. 입력 우선순위와 합성, 해제·취소·포커스 상실 때의 초기화 동작을 구현하고 검수합니다.
